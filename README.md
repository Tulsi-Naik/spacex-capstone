# SpaceX Falcon 9 First Stage Landing Prediction

This project was completed as part of the IBM Data Science Professional Certificate Capstone.

The objective of the project is to predict whether the Falcon 9 first stage will successfully land after launch. Accurate landing prediction helps estimate launch costs because SpaceX significantly reduces mission expenses through reusable rocket technology.

## Project Workflow

- Data Collection using SpaceX REST API
- Web Scraping launch records from Wikipedia
- Data Wrangling and Feature Engineering
- Exploratory Data Analysis (EDA)
- SQL-based Data Analysis
- Interactive Geographic Visualization using Folium
- Interactive Dashboard Development using Plotly Dash
- Machine Learning Classification and Model Evaluation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Folium
- Plotly Dash
- Scikit-learn
- Jupyter Notebook

## Project Results

- Analyzed 90+ Falcon 9 launches
- Identified key factors influencing landing success
- Developed interactive maps and dashboards for exploration
- Compared multiple machine learning models
- Achieved a best classification accuracy of 83.3%
